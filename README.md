# Пара Палок — сайт кафе

Две страницы на чистом HTML/CSS/JS, без сборки и зависимостей.

- `index.html` — главная.
- `menu/index.html` — полное меню (открывается по адресу `/menu/`).
- `assets/data/menu.js` — единый каталог: 103 позиции (98 из menu.pdf + «Калифорния с креветкой», «Калифорния с угрём», «Пицца Томаты Страчателла», «Вок овощной» и круглая «Пицца Мясная», добавлены вручную), 14 категорий, все названия,
  составы, выход и цены перенесены из `menu.pdf` (поле `page` — страница PDF).
- `assets/images/menu/` — фотографии блюд, вырезанные из `menu.pdf`
  (`<id>.webp` до 1000 px и `<id>-480.webp` для телефонов).
- `assets/images/site/` — обложка меню, фото для hero, эмблема.

## Как редактировать меню

1. Откройте `assets/data/menu.js`.
2. Чтобы изменить цену или состав — поправьте нужную запись в `items`.
3. Чтобы добавить блюдо — скопируйте любую запись, задайте уникальный `id`,
   `category` из списка `categories`, положите фото `assets/images/menu/<id>.webp`
   и `<id>-480.webp` (или не указывайте `image` — карточка отрисуется без фото).
4. `popular: true` выводит блюдо в блок «Популярные блюда» на главной,
   `featured: true` у сета — в блок «Наши сеты».

## Политика конфиденциальности и cookie

- Страница политики: `privacy/index.html`. Перед публикацией впишите реквизиты оператора (ИП/ООО, ИНН, ОГРН, e-mail) — место отмечено комментарием в начале `<main>`.
- Уведомление о cookie создаётся скриптом `assets/js/site.js` (функция `initCookieNotice`). После нажатия «Принять» в `localStorage` записывается ключ `parapalok-cookie-ok`, и уведомление больше не показывается.
- Если подключите аналитику (Яндекс Метрика и т. п.), дополните раздел 4 политики и текст уведомления.
- Мессенджеры: WhatsApp и Telegram — по номеру +7 916 442-44-03, MAX — по ссылке профиля; заказ из корзины уходит в WhatsApp на этот же номер (`ORDER_WA` в `assets/js/site.js`).
- После правок CSS/JS увеличивайте номер `?v=` в ссылках на файлы во всех трёх HTML, иначе браузер покажет старую версию.
- Яндекс Карта в блоке «Контакты» подключена через JS API 2.1 и загружается сразу после загрузки страницы. Впишите ключ JS API (developer.tech.yandex.ru) в атрибут `data-apikey` у `<div id="map">` в `index.html` — без ключа карта отображается блёклой.
- Корзина — компонент Offcanvas из Bootstrap 5.3.3. Скрипт лежит в `assets/vendor/bootstrap/bootstrap.bundle.min.js`, из CSS подключены только стили offcanvas (`assets/vendor/bootstrap/offcanvas.css`), чтобы Bootstrap не менял оформление остального сайта.
